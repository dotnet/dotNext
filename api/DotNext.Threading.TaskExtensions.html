YieldToThreadPool()

Yields control to the caller and resumes the asynchronous method on ThreadPool.

Declaration
public static ConfiguredTaskAwaitable YieldToThreadPool()
Returns
Type Description
ConfiguredTaskAwaitable

The awaitable object that resumes the caller on the thread pool.
Remarks

In contrast to Yield(), the continuation ignores the current SynchronizationContext and TaskScheduler. For instance, awaiting this method inside a task scheduled by ExclusiveScheduler leaves the exclusive scheduler. The method always yields, even if the caller is already running on the thread pool.
