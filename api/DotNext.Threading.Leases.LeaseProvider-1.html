Syntax
public abstract class LeaseProvider<TMetadata> : Disposable, IDisposable
Type Parameters
Name Description
TMetadata

The type of metadata associated with a lease.
Remarks

An instance of this type must support concurrent calls.

Each instance tracks the lease expiration using its own monotonic clock, starting from the moment it observes a particular version of the lease. Thus, the wall clocks of the instances sharing the same storage don't need to be synchronized. As a consequence, a newly created instance waits for the full TimeToLive before taking over the lease that was not released explicitly. Call ObserveAsync(CancellationToken) immediately after the instantiation to start tracking the expiration as early as possible.

The lease is held on behalf of the owner identified by Guid. The owner must be unique across all consumers of the lease. Acquisition, renewal and release by the owner don't require the actual version of the lease. Thus, these operations can be retried safely if the response is lost.

TryUpdateStateAsync(LeaseState<TMetadata>, LeaseState<TMetadata>, CancellationToken)

Attempts to update the state in the underlying storage using compare-and-set semantics.

Declaration
protected abstract ValueTask<bool> TryUpdateStateAsync(LeaseState<TMetadata> expected, LeaseState<TMetadata> update, CancellationToken token)
Parameters
Type Name Description
LeaseState<TMetadata> expected

The state previously returned by GetStateAsync(CancellationToken).
LeaseState<TMetadata> update

The state to be stored in the underlying storage.
CancellationToken token

The token that can be used to cancel the operation.
Returns
Type Description
ValueTask<bool>

true if update is performed successfully; false is compare-and-set failed.
Remarks

The operation must use compare-and-set semantics in the following way: save update only if Version and RenewalStamp of the currently stored state are equal to the corresponding properties of expected. Other properties must not be compared. If the lease doesn't exist in the storage, save update only if the lease is still absent. Note that the method can be called concurrently.
