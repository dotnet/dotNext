Class AsyncParkingLot

Represents a set of wait queues shared by many lightweight asynchronous locks.

public class AsyncParkingLot : Disposable, IDisposable
Remarks

Each lock is represented by a field of type AsyncParkingLot.State owned by the caller, so the lock itself doesn't require any allocation. The wait queue is allocated only for the contended locks. The lock is identified by its position and optional user data. The positions mapped to the same slot share the wait queue, but they don't block each other.

The ownership is handed off to the first waiter on release, so the waiters are resumed in FIFO order. The lock is not reentrant and doesn't track the owner.
