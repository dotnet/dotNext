Class RandomAccessCache<TValue>

Represents concurrent cache optimized for random access, which keeps the entries in unmanaged memory.

public sealed class RandomAccessCache<TValue> : Disposable, IDisposable, IAsyncDisposable, Epoch.INativeResourceManager where TValue : unmanaged
Type Parameters
Name Description
TValue

The type of the values.
Remarks

The cache entries are not visible to GC, so the size of the cache doesn't affect GC pauses. The key is a sequence of bytes copied to the cache entry. The value of the entry cannot be modified after insertion. All the sessions must be disposed. The cache evicts older records on overflow using SIEVE algorithm.

Property Value

ReadOnlySpanAction<byte, TValue>
Remarks

The callback is invoked once for every cache record when the record is no longer available: it is evicted or invalidated, and all the sessions associated with the record are closed. The callback is invoked for the remaining records when the cache is disposed as well. If the cache is not disposed explicitly, the finalizer releases the memory without calling the callback. The key is valid only during the call. The callback should not throw: the exception propagates to the caller that released the record, which can be the background eviction process.
