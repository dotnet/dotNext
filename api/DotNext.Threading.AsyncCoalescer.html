Class AsyncCoalescer

Coalesces concurrent callers into a single invocation of the asynchronous action.

Remarks

The first caller of WaitAsync(CancellationToken) opens the time window. The callers arriving within the window are suspended and join the same batch. When the window expires, or Flush() is called, the window is closed, and the action is invoked once for all the callers of the batch. The suspended callers are resumed when the action completes.

The action always starts after all the callers of the batch have joined it. Therefore, the completion of the action observed by the caller is caused by the invocation started after the call to WaitAsync(CancellationToken). The callers arriving while the action is in progress open the next window and never observe the completion of the action started before them.

The window is fixed: it's not extended by the callers arriving within it. The next window is opened by the first caller after the closure of the previous window, so the actions of the consecutive windows can run concurrently.

The action runs on the thread pool without the ExecutionContext of the callers.
